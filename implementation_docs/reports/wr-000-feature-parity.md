## Exact table and sorting contract

The current table passes no initial sorting state to TanStack Table, so no column sort is active on first render. It preserves its input order: filesystem discovery is newest-first and the correlator also emits reverse chronology. Clicking any sortable data header toggles that column's ascending/descending sort and displays the arrow state. The current implementation paginates at 100 rows; WR-009's binding UI brief deliberately replaces that with one virtualized list.

| Category family | Columns, left to right | Explicit comparator where present |
|---|---|---|
| Raids | Details, Encounter, Result, Pull, Difficulty, Duration, Date, Viewpoints, Creator | Details `detailSort`; Result `resultSort`; Duration `durationSort`; Viewpoints `viewPointCountSort`; Creator `creatorSort`; other columns use TanStack inferred sorting |
| 2v2, 3v3, 5v5, Skirmish, Solo Shuffle | Details, Map, Result, Duration, Date, Viewpoints | Details `detailSort`; Result `resultSort`; Duration `durationSort`; Viewpoints `viewPointCountSort`; Map and Date inferred |
